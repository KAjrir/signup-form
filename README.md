# Sign-up Form

A responsive sign-up form built as part of [The Odin Project](https://www.theodinproject.com/).

## Features
- Two-column layout with a hero image
- Client-side validation with `required`, input types (`tel`, `password`) and `pattern`

## Built with
HTML and CSS (custom fonts)

## What I learned
- Native HTML form validation without JavaScript
- Making forms accessible with proper `label`s
